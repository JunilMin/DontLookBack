# Don't Look Back

관찰하고 있는 공간만 현실에 고정되는 탑다운 2D 심리 공포·공간 퍼즐 게임입니다.

## 현재 프로토타입

`SampleScene`을 Play하면 별도 설정 없이 테스트 시설이 자동 생성됩니다.

- 31×31 셀, 961개 구획으로 구성된 실제 고정 미로
- 미로 중앙의 관찰실에서 시작해 가장 먼 외벽 출구로 탈출
- 어둠 속에서 가까운 전력 제어실을 찾아 주 전원을 복구하는 시작 퀘스트
- 전력 복구 즉시 시설 전체 전역 조명이 켜지고 출구 탐색 단계로 전환
- 캐릭터의 시선과 이동 방향 분리
- 58도 범위의 좁은 손전등 시야와 거의 완전한 암흑
- 출구까지의 실제 정답 경로에 흩어진 시설 기록·배관·대피도 단서
- 동서 구역과 수몰·연구·감시 구역을 조합한 위치 추론
- 실제 미로 좌표에 남아 되돌아갈 때 다시 발견할 수 있는 분필 표시
- 집중해서 들으면 출구 방향의 바람을 짐작할 수 있는 청각 단서
- 보지 않는 동안 두 위치 사이를 이동하는 관찰 이상 현상

## 조작

| 입력 | 행동 |
| --- | --- |
| `WASD` / 방향키 | 이동 |
| 마우스 | 바라보는 방향 |
| `E` | 전력 장치 등과 상호작용 |
| `Q` | 현재 방에 분필 표시 |
| `F` 누르기 | 집중해서 듣기 |

자동 지도는 제공하지 않습니다. 시설 단서, 구역명, 바람 소리와 직접 남긴 분필을 조합해 중앙에서 외벽으로 나아가야 합니다. 붉은 관찰 이상 표식은 바라보는 동안 고정되지만 시야 밖에서는 다른 위치로 이동합니다.

메모 가까이에서는 `E`로 내용을 열 수 있고, 열린 상태에서 `E`를 다시 누르면 닫힙니다. 메모를 읽는 동안에는 이동이 멈춥니다. 주 전력을 복구하면 시설 전체 조명이 켜지고 손전등은 자동으로 꺼집니다.

## 개발 환경

- Unity `6000.3.19f1`
- Universal Render Pipeline 2D
- Input System
- Unity Test Framework

EditMode 테스트는 대형 미로 전체의 연결성, 중앙 시작, 외벽 출구, 정답 경로와 관찰 연결 규칙을 검증합니다.
