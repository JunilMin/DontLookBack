# Don't Look Back

관찰하고 있는 공간만 현실에 고정되는 탑다운 2D 심리 공포·공간 퍼즐 게임입니다.

## 현재 프로토타입

`SampleScene`을 Play하면 별도 설정 없이 테스트 시설이 자동 생성됩니다.

- 캐릭터의 시선과 이동 방향 분리
- 시야 안의 문 연결 고정
- 시야 밖에 1.35초 이상 놓인 문 연결 변경
- 안전실, 사무동, 발전실, 침수실, 출구 관찰실
- 방에 귀속되는 분필 표시
- 방마다 다른 청각 단서
- 발전기를 가동하고 출구를 찾는 짧은 목표

## 조작

| 입력 | 행동 |
| --- | --- |
| `WASD` / 방향키 | 이동 |
| 마우스 | 바라보는 방향 |
| `E` | 문 사용 / 장치 작동 |
| `Q` | 현재 방에 분필 표시 |
| `F` 누르기 | 집중해서 듣기 |

문을 계속 바라보면 현재 연결이 유지됩니다. 고개를 돌린 채 기다리면 벽 속 마찰음과 함께 문이 다른 방으로 이어집니다.

## 개발 환경

- Unity `6000.3.19f1`
- Universal Render Pipeline 2D
- Input System
- Unity Test Framework

EditMode 테스트는 관찰 중인 문이 유지되고 관찰하지 않은 문의 연결이 예측 가능한 순서로 변하는지 검증합니다.
